# Fama-French 5-Factor Attribution & Statistical Robustness Specification

## 1. Factor Data Sources & Ingestion Pipeline (#203–#205)

### 1.1 Kenneth French Data Library (FF5 Daily Series)
* **Dataset Identifier:** `F-F_Research_Data_5_Factors_2x3_daily` (Tuck School of Business at Dartmouth, Kenneth R. French Data Library).
* **Primary Ingestion:** Retrieved programmatically via `pandas_datareader.data.DataReader(..., "famafrench")`, with an automatic deterministic fallback to the Dartmouth FTP archive (`F-F_Research_Data_5_Factors_2x3_daily_CSV.zip`).
* **Local Cache Artifact:** Persisted at `data/ff5_factors_daily.csv` (`2000-01-03` through `2026-09-30`, 6,726 trading sessions) to guarantee deterministic offline execution across regression and Monte Carlo permutation runs.
* **Unit Normalization (#205):** Raw Kenneth French tables report daily returns in percentage units (e.g., `-0.82` denoting $-0.82\%$). All factor columns (`Mkt-RF`, `SMB`, `HML`, `RMW`, `CMA`, `RF`) are divided by $100.0$ upon ingestion so every series is stored in floating-point decimal representation (`-0.0082`).

### 1.2 Factor Definitions & Economic Interpretation
| Factor | Series Name | Economic Risk Premium Captured |
| :--- | :--- | :--- |
| `Mkt-RF` | Market Excess Return | Value-weighted CRSP U.S. equity market return minus the one-month Treasury bill daily rate (`RF`). |
| `SMB` | Small Minus Big | Size factor: return spread between small-cap and large-cap equity portfolios. |
| `HML` | High Minus Low | Value factor: return spread between high book-to-market (value) and low book-to-market (growth) stocks. |
| `RMW` | Robust Minus Weak | Profitability factor: return spread between firms with robust operating profitability and weak profitability. |
| `CMA` | Conservative Minus Aggressive | Investment factor: return spread between firms that invest conservatively and those that invest aggressively. |
| `RF` | Risk-Free Rate | Daily compounded one-month U.S. Treasury bill return used to compute daily strategy excess returns. |

## 2. Causality, Lag Assumptions & Calendar Alignment (#207)

### 2.1 Execution Lag & Point-in-Time Causality
* **Constituent Entry/Exit Lag ($t + 1$):** Universe membership (`data/universe_mask.csv`) incorporates a strict $+1$ trading-day execution lag following public CEO appointment or departure announcements so portfolio weights at session $t$ never condition on contemporaneous or future corporate news.
* **Estimator Lookback Lag ($t - 1$):** All rolling covariance ($\Sigma^*_t$) and cross-sectional quality tilt ($q_t$) inputs are estimated strictly over trailing sessions $[t - W, t - 1]$ ($W = 63$ trading days) prior to rebalance execution at session $t$.
* **Contemporaneous Return Attribution:** Because realized portfolio net return $r_{p, t}$ at session $t$ is generated by pre-committed weights $w^{\text{target}}_t$ held across trading session $t$, $r_{p, t}$ is aligned contemporaneously (`inner join` on tz-naive `DatetimeIndex`) with session-$t$ Fama-French factor realizations $f_t$.

### 2.2 Excess Return Formulation & Sample Truncation
* For every overlapping trading session $t \in \mathcal{T}_{\text{strategy}} \cap \mathcal{T}_{\text{FF5}}$, daily portfolio excess return $R_{p, t}^e$ is computed using the contemporaneous Kenneth French daily Treasury bill rate `RF`$_t$:

$$
R_{p, t}^e = r_{p, t}^{\text{net}} - R_{f, t}
$$

* Because the Kenneth French daily archive updates on a periodic lag relative to real-time exchange closes, inner-joining onto $\mathcal{T}_{\text{FF5}}$ restricts attribution inference strictly to verified historical factor dates without forward-filling or extrapolating missing factor observations.

## 3. Econometric & Robustness Methodology Overview (Issues #197–#200)

* **5-Factor Time-Series OLS Specification:**

$$
R_{p, t}^e = \alpha + \beta_{\text{MKT}} (\text{Mkt-RF})_t + \beta_{\text{SMB}} \text{SMB}_t + \beta_{\text{HML}} \text{HML}_t + \beta_{\text{RMW}} \text{RMW}_t + \beta_{\text{CMA}} \text{CMA}_t + \varepsilon_t
$$

* **Heteroskedasticity & Autocorrelation Consistent (HAC) Inference:** Standard errors and $t$-statistics are computed using Newey-West HAC covariance estimators (`maxlags = 5`) to account for daily volatility clustering and serial correlation.
* **Annualized Alpha Scaling:** Daily intercept $\hat{\alpha}$ is annualized via $\hat{\alpha}_{\text{annual}} = 252 \cdot \hat{\alpha}$ (arithmetic) alongside compound annualized alpha $(1 + \hat{\alpha})^{252} - 1$.
